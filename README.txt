EDITORIAL - SIMPLIFIED STATIC TEMPLATE

This is a lightweight, multi-page HTML setup using a simplified stylesheet inspired by HTML5 UP Editorial.

FILES
- index.html: homepage
- article-template.html: copy this file to create a new article page
- generic.html: sample article page
- elements.html: basic HTML element examples
- assets/css/main.css: shared site appearance
- assets/js/main.js: shared sidebar toggle and submenu behavior
- images/: original Editorial sample images used on the homepage and article page
- LICENSE.txt: Creative Commons Attribution 3.0 license supplied with the original template

TO CREATE A NEW PAGE
1. Copy article-template.html.
2. Rename the copy, for example: new-article.html.
3. Change the page <title> and the <h1> heading.
4. Replace the article content inside the main <section>.
5. Add a link to the page in the sidebar menu on each page where it should appear.

IMPORTANT
- Keep all HTML pages in the repository root so the relative asset paths continue to work.
- Each page includes the same sidebar markup. If you change the sidebar, copy that change to the other HTML pages too.
- All pages share one CSS file and one JavaScript file. Styling or sidebar behavior changes in those files apply site-wide.
- The Search field is visual only; it is not connected to a search engine.
- The header text remains “Editorial by HTML5 UP”. No faction branding has been added.
- Preserve the HTML5 UP attribution and the included license when distributing this adapted template.
